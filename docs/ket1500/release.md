# KET1500 发布说明

## 2026-10-17 / ket1500-v1

用户已确认本轮内容审核通过，并要求部署到线上、开放已有客户使用。

- 正式运行时通过 `lib/ket-curriculum.js` 接入1500词、150单元。
- 前100词的ID、所属单元、例句与图片保持不变，历史学习记录和未完成会话继续有效。
- `KET_ACCESS=full` 时，正常完整英语权益客户可使用全部单元；有效免费体验账号限前两个单元。禁用、到期、中文主课程账号继续受限。
- 新增情境配图只用于学习展示；答题接口不返回这些图片，采用中文释义选项。保持 `quizSafe: false`。
- 发音沿用腾讯云；不改变奖励、账号、数据库结构及原英语/中文课程。
- 教师专业复核、官方词表逐项核对及真实发音试听不因用户确认而自动标记完成。

`catalog.json`、`validation.json` 和 `approval.md` 保留内容审核时的快照及哈希，其100词试点/1400词草稿标记为当时状态，不代表当前运行时课程数量。运行时发布版本以本说明和 `lib/ket-curriculum.js` 为准。

## 部署与回退

部署前使用SQLite在线备份保存 `data/app.db`，校验备份完整性；另外保留 `.env` 和当前Git提交号。拉取时保留服务器原有 `ecosystem.config.cjs` 本地修改。

运行测试后将服务器 `.env` 中 `KET_ACCESS` 设置为 `full`，重启英语服务并同步PM2环境变量。验证登录页、KET目录、资产加载和客户权限。

紧急关闭入口：将 `.env` 中 `KET_ACCESS` 改为 `admin` 或 `off`，并用相同值同步PM2环境后重启。不要删除任何学习记录或直接用旧备份覆盖已有的新学习数据。代码回退到100词试点时，新增词的未完成会话不能继续，应保持KET关闭直到恢复完整词库版本。
