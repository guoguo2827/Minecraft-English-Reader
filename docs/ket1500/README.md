# KET1500 儿童学习词库

2026-10-17：用户内容审核通过并授权发布，完整课程接入及权限规则见 [发布说明](release.md)。以下内容准备状态保留审核快照，不作为运行时上线词数的依据。

这是项目自编的 1500 个学习条目（1435 个单词 + 65 条多词表达），不是剑桥官方固定的“1500词”，也不代表完整考试覆盖。范围参考 [Cambridge A2 Key / A2 Key for Schools vocabulary list, August 2025](https://www.cambridgeenglish.org/images/506886-a2-key-2020-vocabulary-list.pdf)，结合儿童日常生活与基础语言表达选词。中文释义与单元编排为本项目整理，不复制商业教材。

## 配图边界

延续试点词库的Twemoji插画体系，使用14.0.2版、CC-BY 4.0授权的矢量素材，组合成640×360的本地SVG，并加入原创英文例句。每张图有来源与SHA-256记录；不使用远程热链、儿童照片或用户上传素材。完整授权见配图目录中的`ATTRIBUTION.md`及`LICENSE-GRAPHICS`。

**这些是情境联想辅助图初稿，不是1400张逐词独立绘制、已经审核的写实插画。** 具体图形不能覆盖每一个词的精确含义。例如某些厨房用具配图表现其使用场景；抽象词主要借助例句与场景要素解释。同义词可能共用图形，部分具体词还需要替换专属图。这一点不能用“图片文件非空”当作完成图义审核。

新增配图含英文例句，统一标记`picture.quizSafe: false`。不得直接导入现有听音选图选项，否则会泄露答案或造成图义歧义。正式上线前应改为无文字且语义清晰的题图，或对不适宜图选的词采用听音选义题型。当前没有修改运行时题库。

## 编辑原则

1. 一个常用词只保留一个学习条目，核心义优先；多义词在释义内补充，不按每种词性重复计数。
2. 英美拼写变体与所选常见等价形式放入 `variants`，不额外计数。`variants` 是本词表的教学归并字段，不表示全部词性和语境下都可以互换，例如 `trainer` 的“教练”义不能替换成 `sneaker`。具有独立用途的短语和短语动词可以单列，并标记 `kind: phrase`。
3. 不把名词的规则复数、动词的规则过去式或进行时单列凑数；不规则形式只在确有独立学习价值时保留。
4. 首 100 词保持原课程顺序；后续按人物、生活、校园、出行、动作、描述、时间、语法与交际展开，每单元 10 条。
5. 中文是适龄核心义，不是完整词典释义。近义词与一词多义上线出题前须额外审核，不能只凭中文字符串不同就认定为有效干扰项。
6. 生活扩展词可能超出官方词表；所有新增条目在逐词核对前都标注 `officialListVerified: false`，不虚构官方认证。

## 上线前

教师复核例句自然度、中文对应、难度及图义；补做不适合联想图的专属配图；调用既有腾讯云TTS抽检单词和例句。然后检查近义词选项歧义，并明确区分学习卡片图与测验题图。每完成一批再加入发布词库，原ID必须保留。维护者确认后才能改变在线课程分母。这次未调用腾讯TTS，不产生语音套餐消耗，也不声称已试听通过。

## 重点复核

- `May / may` 归在同一词条，并标明大小写区别。月份与情态动词应在课程中分情境练习，不拆成两个计数条目。
- `PE`、`Wi-Fi` 等缩写应逐项试听，不能仅凭接口返回音频就判定读音正确。
- `a / an`、代词、介词、连词等抽象条目应使用场景句，不强行用单张物品图表示。
- `happy / pleased`、`ill / sick`、`fix / repair` 等近义词不得在缺乏上下文时互作唯一正误选项。
- `skating`、`painting` 等以活动或名词义独立收录；`better` 等不规则比较形式保留教学价值。不把规则变化全量展开计数。
- 这份词表覆盖基础交际与生活扩展；尚未逐条核对官方收录和适龄难度，不能据此宣称每条都是官方A2必考词。

## 生成和检查

在项目目录运行：

```bash
node scripts/build-ket-lesson-art.js
node scripts/build-ket-catalog.js
node scripts/build-ket-lesson-art.js --check
node scripts/build-ket-catalog.js --check
node --test test/ket-catalog.test.js
node scripts/verify-ket-catalog-ui.js
```

图片已保存在仓库中，日常检查不需要联网。首次缺少素材时，配图脚本会从官方固定版本下载；也可通过`--source-dir=路径`使用已解压的官方`assets/svg`目录。检查模式不下载或补齐缺失文件。

检查包括1500条总数、150个单元、每单元10条、ID及词形/变体冲突、1400条例句/翻译覆盖、例句重复、素材哈希、SVG重建一致性、原100词字段不变、导出文件一致性。界面检查使用临时本地服务，不连接用户数据库。`validation.json`只记录结构检查与覆盖数量，不是教师审核或图义正确性的证明。
